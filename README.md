# Java Practice & Fundamentals

This repository is a comprehensive collection of Java programs ranging from basic logic and mathematical operations to advanced Object-Oriented Programming (OOP) concepts. 
It serves as a personal knowledge base for mastering Java for Software Quality Assurance and Automation Testing.

##  Project Structure

The project is organized into packages based on core Java concepts:

* **`com.java_fundamentals`**: Basic syntax, variables, and data types.
* **`com.loopingstatements`**: Implementation of for, while, and do-while loops.
* **`com.decisionmakingstatements**: Examples of if-else, nested-if, and switch-case.
* **`com.arrays`**: Array manipulation, sorting, and searching logic.
* **`com.inheritance`**: Demonstrating OOP principles like Parent-Child relationships.
* **`javaprograms`**: A collection of 20+ Must-Know interview programs.
